# Stitch design exports

Generated with Google Stitch (project "SearchLab v2") from `DESIGN.md` and `prompts.json`.
Each screen has a PNG and the exported HTML. The app is built from these layouts in Next.js.

Stitch filled the mockups with invented numbers (for example "text-embedding-3-large", "1538-dim",
latencies and scores). The app shows only real values from the API: `text-embedding-3-small`,
1,536 dimensions, and live scores and latencies.
